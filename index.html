01 / TENTANG PROJEK

ECOENERGY MONITOR

Satu sistem untuk pantau, kawal dan optimumkan penggunaan elektrik.

Projek ini dibangunkan untuk memantau penggunaan tenaga elektrik fasa tunggal menggunakan ESP32 dan sensor PZEM-004T. Data penggunaan elektrik dihantar melalui sambungan Wi-Fi ke Firebase Realtime Database sebelum dipaparkan pada dashboard web.

Pengguna boleh melihat voltan, arus, kuasa, tenaga, anggaran kos, status peranti serta mengawal relay ON dan OFF dari jauh.

02 / CIRI UTAMA

SMART ENERGY PLATFORM

Dibina untuk pemantauan sebenar.

Data sensor dihantar daripada PZEM ke ESP32, kemudian ke Firebase dan dipaparkan pada dashboard. Arahan kawalan daripada dashboard pula dihantar semula kepada ESP32 untuk mengawal relay.
